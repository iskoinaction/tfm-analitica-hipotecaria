Modelo Tipo MAPE Ventaja

MAPE = Mean Absolute Percentage Error. Menor es mejor. Los modelos están documentados en el notebook data_science_provincial.ipynb.

Metodología (data_science_provincial.ipynb):
  • Modelos de demanda: RF_Nac para el total nacional y Random Forest provincial con features de lags temporales para evitar data leakage.
  • Stress Test: Se varia el Euribor manteniendo el resto de variables constantes (ceteris paribus) para medir la elasticidad de la demanda.
  • Forecast: Proyeccion a 20 trimestres (2026-2030) usando la ultima observacion de cada provincia como base.
  • Variables lag1: Precio_m2, Spread, Población, Edad Media, Transmisiones, Paro, Ahorro, PIB pc, Pob. Extranjera + Inercia (Hipotecas_lag1) + Trimestre.
